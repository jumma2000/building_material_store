# نظام إدارة متجر مواد تنظيف
 (Building Materials Store Management System)

نظام متكامل ومخصص لإدارة متجر مواد مواد تنظيف ، يتيح التحكم الكامل في المخزون، المبيعات، المشتريات، العملاء، والموردين، مع مراعاة وحدات القياس الخاصة بمواد مواد تنظيف  وإصدار التقارير المالية والإدارية بدقة وسهولة، مبني باستخدام إطار العمل **Django**.

---

## 🏗️ نظرة عامة ومميزات النظام

* **إدارة المنتجات ووحدات القياس الخاصة:** تتبع الأرصدة مع دعم وحدات القياس الخاصة بمواد مواد تنظيف  (مثل: كيس، طوبة، متر، برميل، إلخ)، وتنبيهات انخفاض المخزون.
* **إدارة المبيعات:** إنشاء فواتير البيع، دعم طرق دفع متعددة (نقدي، شبكة، أجل)، وتحديث المخزون آلياً.
* **إدارة المشتريات:** تسجيل فواتير الموردين، تحديث أسعار الشراء، وتتبع حركة المخزون الواردة.
* **العملاء والموردين:** إدارة بياناتهم وتسهيل عمليات الفوترة والمتابعة.
* **التقارير الشاملة:** 
  * لوحة تحكم رئيسية (Dashboard) تعرض إحصائيات عامة.
  * تقارير المخزون والأرصدة.
  * تقارير المبيعات والمشتريات المفصلة.
  * تقارير الأرباح وهامش الربح.
* **إدارة الحسابات:** تسجيل المستخدمين، تعديل الملف الشخصي، وتغيير كلمات المرور مع صلاحيات أمان كاملة (`LoginRequiredMixin`).
* **حماية متكاملة:** تطبيق معالجة الأخطاء الشاملة (`try-except`) ومعاملات قاعدة البيانات (`transaction.atomic`) لضمان سلامة البيانات ومنع حدوث أي تعارضات.

---

## ⚙️ التقنيات المستخدمة والمتطلبات الأساسية

* **Python 3.10** أو أحدث.
* **Django 6.0.3**
* **Bootstrap 5 (RTL)** لتصميم متجاوب يدعم اللغة العربية بالكامل.
* **SQLite** (قاعدة البيانات الافتراضية).
