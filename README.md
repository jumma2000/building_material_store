# نظام إدارة متجر مواد البناء

## نظرة عامة
نظام متكامل لإدارة متجر مواد البناء، يشمل:
- العملاء
- الموردين
- المنتجات (مع وحدات قياس خاصة بمواد البناء: كيس، طوبة، متر، برميل، إلخ)
- المخازن
- المشتريات
- المبيعات
- التقارير

## التقنيات المستخدمة
- Django 6.0.3
- Bootstrap 5 (RTL)
- SQLite
